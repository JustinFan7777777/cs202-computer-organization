# CS202 — Computer Organization

Coursework for **CS202 Computer Organization**, covering RISC-V assembly programming and processor architecture using the RARS simulator.

## Contents

### Assignments

| # | Topic |
|---|---|
| 1 | RISC-V basics — arithmetic and control flow |
| 2 | Procedures and stack management |
| 3 | Memory access and arrays |

### Labs

| # | Topic |
|---|---|
| 3 | Introduction to RISC-V assembly |
| 4 | Branches and loops |
| 5 | Procedures and calling conventions |
| 6 | Memory and data structures |
| 7 | I/O and system calls |
| 8 | Advanced assembly techniques |
| 10 | Single-cycle processor design |
| 11 | Pipelined processor design |

## Tools

- **RARS** (RISC-V Assembler and Runtime Simulator) — included as `Rars Assembler.jar`
- **Lars** (alternative simulator) — included as `Lars.jar`

### Running a Program

```bash
java -jar "Rars Assembler.jar" <program.asm>
```

## Topics Covered

- RISC-V instruction set architecture
- Assembly programming
- Procedure calling conventions
- Memory hierarchy
- Single-cycle CPU design
- Pipelined processor architecture
- Data hazards and forwarding
